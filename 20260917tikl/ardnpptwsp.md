# 胚胎植入前筛查，免费啦！

> 更新时间：2026-09-17 (UTC+8)

**这么好的福利，快来了解一下！**

试管婴儿技术的诞生为千万不孕症家庭带来了“重获新生”的喜悦，但仍有一些患者被**反复流产、胎儿染色体异常、多次胚胎移植失败**等问题困扰。在传统的试管婴儿中，移植胚胎的选择主要依靠医生通过显微镜对其形态进行鉴定，而无法对胚胎的遗传物质进行筛选。所以仍有一定比例的胚胎不能成功着床或持续妊娠。其主要原因之一是形态学评估较好的胚胎仍可能存在染色体异常，从而失去了发育的能力导致着床失败或流产。

胚胎植入前遗传学筛查 (PGS)---第三代试管婴儿的一种，是将体外受精的胚胎培养至囊胚期，然后提取几个细胞进行染色体检测，以鉴定胚胎是否存在染色体非整倍体异常，进而挑选未发现异常的胚胎进行移植的一种**胚胎优选技术**。我中心自2017年12月开展PGD/PGS以来，陆续为两百多个家庭送去了活泼、健康的宝宝。目前我生殖中心正在开展一项**全国多中心**胚胎植入前筛查的临床研究，本次临床研究应用高通量测序（NGS）技术对植入前胚胎的全部染色体进行非整倍体检测，从而鉴定胚胎染色体的数目是否正常。有助于**提高**临床妊娠率、**减少**流产率的发生。但由于本次研究中试剂盒限制，该研究**不能筛查出**单基因病、染色体结构易位（如：平衡易位、罗氏易位等）的胚胎。**不适用于**单基因病、平衡易位等疾病。

**
**

**招募对象：**

本中心进行辅助生殖技术助孕，自愿参加本次临床研究患者。

**入选条件：**

1.夫妻双方或一方存在染色体异常的患者；

2.生育过染色体异常患儿的患者或流产后绒毛膜组织提示有染色体异常的患者；

3.≥3次体外受精-胚胎移植失败的患者；

4.≥2次自然流产史的患者；

5.女性年龄≥38岁；

6.因男性因素须做ICSI的患者（如严重畸精子症）。

**当发生下列情形之一的患者不应纳入本试验：**

1. 卵巢反应低下（如AFC＜5，AMH＜1.1ng/ml，FSH＞12等）；

2. 受试者存在具有临床意义的不适宜妊娠的系统性疾病；

3. 同时参与其他临床研究；

4. 研究者认为不适合入选的其他情况。

**入选患者享有以下权益：**

1．符合条件患者可获得免费的胚胎植入前非整倍体检测、产前羊水DNA的染色体检测或免费羊水穿刺G显带核型分析； 

2. 贡献有效胚胎样本有3000元补贴（包括交通补贴）； 

3. 胚胎不符合研究要求而脱落仍可获得1000元补贴（包括交通补贴）。 

以上均需患者先行支付，研究结束后凭发票返还。.

**入选者的义务：**

1.自加入本研究开始接受生殖中心专人随访；

2.每次选取一个检测结果正常（无染色体异常发现）的胚胎进行胚胎移植；

3.成功妊娠后，孕16-20周进行胎儿羊水穿刺产前遗传学基因染色体诊断（NGS）及核型分析。如特殊情况未能获得羊水穿刺检测结果，则需要在新生儿出生时采集新生儿脐带血进行检查。

**咨询方式：**
